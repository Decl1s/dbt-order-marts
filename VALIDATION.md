# Фактические проверки

22.10.2026, версия 0.1.0. Локальная ОС Linux amd64; Python 3.12.15, uv 0.13.1,
dbt Core 1.12.3, dbt-duckdb 1.11.0, DuckDB 1.5.0. Universal uv.lock содержит
60 сторонних пакетов, на Linux установлены 59. Установка только в .venv проекта.

Первая настоящая сборка: 2 seeds, 5 моделей, 22 data tests, PASS=29, ERROR=0,
SKIP=0. Проверены значения факта: 6 заказов, gross=85000, refunded=8000, net=77000;
дневная витрина содержит четыре строки и пять оплаченных заказов.

Во время разработки обнаружены и исправлены: deprecated target-path в YAML,
сохранение BIGINT старой seed-таблицы после изменения column_types на VARCHAR
(теперь build использует --full-refresh), неверное расположение аргументов docs
generate. Эти наблюдения описаны в NOTES.md. Окончательные результаты полного
smoke, упаковки и публикации добавляются ниже после фактических проверок.

## Область проверки

Проверяются логические значения и отказы, не равенство байтов DuckDB. Нет заявления
об общей транзакции всех моделей, exactly-once, аварии питания, нескольких писателях
или производственной нагрузке. Сканер исходников — дополнительный фильтр контактов,
типовых секретов и приватных путей, не полноценный аудит безопасности.
Конфигурации VS Code подготовлены; фактические нажатия F5/F9 не проверены.

## Завершённые локальные проверки

Пройдены 12 unittest: 9 мастерская, 3 публикация. Настоящий smoke завершился
кодом 0: 8 сборок dbt; baseline, равный повтор, превышенный возврат и восстановление,
дубль заказа, неизвестный order_id, неизвестный статус, дробная копейка. Проверены
FAIL соответствующего условия, SKIP зависимой витрины, блокировка старого отчёта,
повторное получение 77000 после исправления. Документация dbt реально сгенерирована:
index.html, manifest.json, catalog.json существуют. Нажатия GUI документации не проверены.

PUBLIC_FILES.txt содержит 38 текстовых исходников. Сканер контактов, типовых секретов,
приватных путей пройден. Базы DuckDB, CSV, логи, target, .venv, результаты и другие
проекты в публикацию не включаются. NOTES.md содержит около 1500 русских слов;
подготовлены 5 упражнений, 6 задач IDE и одна конфигурация отладки.
