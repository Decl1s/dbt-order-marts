# С чего начать

Открой каталог этого проекта в VS Code; в мастерской серии он добавлен отдельно.
Установи окружение по README. Затем Terminal → Run Task: 01, 02, 03.
Первая задача создаёт копии данных, вторая выполняет SQL и тесты, третья читает снимок.
Задача 01 повторно отказывает, чтобы сохранить твои изменения. Остальные задачи:
04 — unittest, 05 — полный smoke на временных копиях, 06 — документация dbt.

| Где | Что и зачем |
| --- | --- |
| scripts/lab.py: ORDERS/REFUNDS | Воспроизводимый пример без внешних данных |
| lab.py: prepare | Создать CSV без перезаписи; --case выбирает учебный сбой |
| dbt_project.yml | Каталоги, материализации и типы seed-таблиц |
| profiles/profiles.yml | Локальный файл DuckDB; DBT_LAB_DB задаёт путь только процессу |
| models/schema.yml | not_null, unique, accepted_values, relationships |
| models/staging | Типизация после тестов сырого входа |
| models/intermediate/int_refunds_by_order.sql | Изменение зерна возвратов до JOIN |
| models/marts/fct_orders.sql | Один заказ, три денежные суммы |
| models/marts/mart_daily_channel.sql | Оплаченные заказы по дате и каналу |
| tests/*.sql | Запросы, возвращающие нарушения; 0 строк = PASS |
| lab.py: build / report | Полный успех, fingerprint и проверенный JSON-снимок |
| scripts/smoke.py | Настоящий dbt, отказы, повтор и восстановление |
| checks/ | Быстрые проверки мастерской и безопасной упаковки |

Проследи O0001: исходная цена 10000; R0001=2000, R0002=1000;
int_refunds_by_order даёт одну строку 3000; факт — gross 10000, refunded 3000,
net 7000. В витрине 01.10 web будет ровно один оплаченный заказ.

В Python можно поставить F9 в fingerprint или report и выбрать готовый запуск F5.
В SQL точки остановки Python не работают: сравни модель, compiled SQL и значения
таблиц через read-only DuckDB. docs generate создаёт каталог и DAG; их наличие
и генерация проверяются отдельно от удобства браузерного интерфейса.
Готовые F5/F9 подготовлены, фактическое нажатие GUI не заявляется без проверки.
Подробные причины решений — DECISIONS.md, следующие изменения — EXERCISES.md.
